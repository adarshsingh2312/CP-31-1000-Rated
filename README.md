# CP-31-1000-Rated
 
Solutions for 1000-rated problems from the [CP-31 Sheet](https://www.tle-eliminators.com/cp-sheet).
 
## Language
 
- C++17 (a few solutions in Java)
 
## Compile and Run
 
```bash
g++ -std=c++17 -O2 -Wall -Wextra problemName.cpp -o problemName
./problemName
```
 
## Commit Convention
 
One commit per solved problem:
 
```text
feat: solve Codeforces <problem-id> - <problem-name>
```
